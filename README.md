# BabelChat 3.3.5a

WoW chat translate. English ↔ Hungarian.

- Work only with **WoW 3.3.5a, enUS client** (Wow.exe, e.g. ChromieCraft). Other client no work.
- Chat come in English → you read Hungarian.
- You write Hungarian → Enter → English go to game chat.
- Windows only. Translate on your PC. No internet, no account.

## Use

1. Copy `addon/BabelChat` to `<WoW>/Interface/AddOns/`.
2. Run `BabelChat.exe`. Folder is everything: move it, delete it, done.
